# Dock icons

The four dock icons use the Phosphor Regular family under the MIT license. Original paths are retained in `components/ShowroomIcon.tsx`, adapted to React and `currentColor`. All four use the same rendered size and weight. The Home and Cars viewBoxes move down four source units to center their painted shapes.

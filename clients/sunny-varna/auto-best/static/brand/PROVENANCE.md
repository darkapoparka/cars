# СЪНИ — local demo artwork

Created 2026-09-09 for the owner's branch-only dealership concept. These are custom vector proposals, not an official original logo and not dealer-approved artwork. The sun/road emblem and name treatment were composed specifically for this preview. Main and subtitle lettering are outlined geometry, with no embedded font or linked font file. Light/dark versions use the same geometry. The favicon uses the matching emblem. A contact-sheet review checked Cyrillic spelling and basic clipping; this is not an application browser check.

Creation method: programmatic custom vector artwork using fontTools outlines. ImageGen was attempted but returned 'Image generation has not started'; no generated image or generation ID is claimed. The published cover reference in CLIENT.md remains unresolved; this is not asserted to be a faithful recreation of the historical cover.

brand-scene.svg is an abstract decorative illustration, not a photo of dealer premises or inventory. stock-unavailable.svg is an explicit missing-photo state, not a stock image. No dealer vehicle photos or image rights were invented. The source-photo access/reuse gap is still open and must not be confused with deferred local runtime testing.

# Monochrome desktop social brand marks

About and Contact use the canonical Simple Icons 16.21.0 vector paths in `src/lib/components/common/social-brand-marks.ts`. They render as 24px inline SVGs in the existing theme ink, with transparent idle surfaces and unchanged 48px link targets. Existing colored footer/mobile assets remain unchanged. Utility icons retain their existing Lucide treatment.

Source geometry is copied unchanged from the pinned upstream SVG paths. No package was installed. The full upstream CC0 license is retained in [LICENSE.simple-icons.txt](LICENSE.simple-icons.txt). This source/license record does not change the configured social destinations.

## Tool issues and limitations

The input checker reproduces retained logos but does not catch every downstream constraint. Exact source-assembly error: `Reviewed onDark has an opaque background or no substantive artwork`. Source artwork was regenerated until the exported PNGs met the existing 25% exact-zero-alpha requirement; no threshold was relaxed.

The Modern composer globally replaces city text inside unquoted TypeScript object keys. MPI emitted `Ras Al Khaimah: "Ras Al Khaimah"` and compilation reported `Expected `,` or `}` but found `Identifier`` in `listing-truth.ts` and `marketplace-control-copy.ts`. MPI, Cantrust and Texas use the government-sourced standard RAK city abbreviation while retaining the full region/address. Tawhib uses its own published Sharjah dealer locality while retaining wider Sharjah / Ajman listing coverage. Shared source is unchanged.

First Edition hit `Explicit reviewed absence/ownership research required` because the identity-source validator accepts HTTPS only. Its reviewed HTTPS dealer catalogue now supplies the required research reference; the public HTTP business website remains separately recorded.

Environment-only public fetches required network-enabled execution after `Failed to connect to browser-proxy port 8889`. GitHub blob transfers were chunked and verified by object SHA; a yielded local read was resumed before committing. No provider writes or relaxed contracts were used.

The inherited Signature desktop example-editorial disclosure limitation documented in PR #16 remains a shared-template issue outside this batch. Inputs do not imply dealer approval, hosted acceptance or release approval.

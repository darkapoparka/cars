3. What the patch fixes
A. Complete inventory overrides inherited sample facts

The documented reuse input is a complete vehicle-card record. Eight consumers instead merged supplied records over sample records. Optional sample fields therefore survived when the supplied record omitted them. The presentation layer could then prefer those inherited semantic fields over supplied display strings. Relevant source: 
reuse contract, lines 17–23, 
sample fields, lines 68–85, 
presentation precedence, lines 37–68.

The regression demonstrated an electric, single-speed, five-seat sales vehicle acquiring sample values including Diesel, Automatic, seven seats, Book Now, per-day pricing, 672 reviews and a sample badge.

The patch adds one 13-line typed resolver and replaces the eight spread merges. A supplied record replaces the complete sample record; only the existing template slot ID is retained. With no supplied override, the existing reference object remains unchanged.

The added regression failed before the fix and passed afterward, covering English and Bulgarian presentation. The full candidate unit runner also passed.

B. Two directions links ignored mapUrl

The contact enquiry and business-preview vehicle heading rebuilt a Google Maps query from the address even when the dealer supplied an explicit mapUrl. Both existing anchors now prefer that configured URL and retain their previous fallback. The map iframe and default presentation are unchanged. Evidence: 
ContactEnquiry, lines 53–57, 
VehicleHeading, lines 89–96.

The configured destination was reviewed statically; a custom-dealer map fixture was not rendered. The default contact page passed the scoped desktop pixel comparison.

C. Demo-form submission leaked entered fields into the URL without JavaScript

DemoForm prevented submission only through its hydrated handler. Its native form had no method, so the named review fields could submit as a GET query. This was reproduced locally with synthetic data, producing a URL containing reviewer, email and comment. Evidence: 
DemoForm, lines 18–25, 
review fields, lines 38–78.

The patch adds method="dialog" to the shared demo form. The actual candidate was checked with JavaScript disabled and enabled:

Native submission no longer navigated or placed the entered values in the query string.
Hydrated submission retained the existing truthful feedback: “Template preview only. This form does not send or save information.”
Measured form/input/textarea geometry was unchanged.

The feedback itself remains the existing implementation. 
DemoFeedback, lines 23–29.

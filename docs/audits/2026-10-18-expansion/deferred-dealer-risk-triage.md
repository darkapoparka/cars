## Release gates for a new dealer

1. **P1 — Import stock facts can change during generation (R6).** `scripts/lib/client-refresh-normalize.mjs:236–238` supplies the current year when source year is missing. `scripts/lib/client-refresh-adapters.mjs` → `importListingFeed` forwards that year in `production`, emits an empty mileage string when unknown, and keeps a per-row currency in the feed price. The runtime `templates/import/src/lib/data/daynight.ts:78–95,137–159` turns empty mileage into **0 km** and strips price to a number; `src/lib/domain/vehicle-card.ts:82–84` and `src/lib/server/vehicle-detail.ts:127,217` expose these facts on real inventory/PDP routes. `src/lib/i18n/formatting.ts:19–39` formats every numeric price with the dealer currency. Thus a USD row in an AED dealer becomes an AED offer without conversion. The existing mileage repair is GB/mi only (`client-refresh-adapters.mjs` → `patchSvelteMileage`); other mile inputs also risk km relabeling. **Hold incomplete/incompatible source records before any Import write**, rather than inventing facts or changing the runtime schema. Null price is already displayed as “On request”; it need not be rejected. Suggested regressions: missing/invalid/conflicting source year, unknown versus genuine zero mileage, non-GB miles, and mixed-currency stock, plus unchanged complete BG/GB/US/AE records. A narrow adapter guard and regression coverage are being prepared separately; publication remains pending.

2. **P1 — Modern claims unverified services for the personalized dealer (PUBLIC-008, adjacent PUBLIC-007).** `templates/modern/apps/web/app/[locale]/contact/page.tsx:58–60` always describes the configured dealer as offering stock, import on request and **in-house leasing**. Identity replacement does not make those facts true. `scripts/lib/client-refresh-adapters.mjs` → `patchModern` changes identity and `staticDemoMode`, but does not derive service flags from evidence; `templates/modern/packages/marketplace/site-config.ts:148–154` defaults imports/lease/sell to true. `applyModernSafeContent` currently repairs Sell copy only (`scripts/lib/client-refresh-safe-content.mjs:444–452`). This reaches a normal public contact route even in a provider-free preview. Gate service claims/metadata on reviewed dealer facts or use factual enquiry wording. Regression: a dealer with no evidenced import/finance service must have no in-house-leasing assertion in localized metadata.

3. **P1 — Import legacy account UI reports nonexistent saves (R1).** `templates/import/src/routes/account/profile/+page.server.ts:47–49` and `account/password/+page.server.ts:47–49` return success without reading or saving. Their page components display “Profile saved locally” / “Password change recorded locally” (`+page.svelte:8–9` / `:7`). The fallback components also set those messages without persistence (`src/lib/components/account/AccountProfileForm.svelte:12–19`, `AccountPasswordForm.svelte:10–16`). These routes are retained in dealer packages; the router delegates the whole design mount (`scripts/publishing/cloudflare-router.mjs:42–52`), and Import hooks do not deny them. The shared `/account` redirect does not remove subroutes (`templates/import/TEMPLATE.md:95–99`). Preview GETs receive synthetic sessions; live GETs are denied by `src/lib/server/auth.ts:173–196`, but the two POST actions omit that guard entirely. A truthful demo-only result or explicit unavailable action is needed before shipping these reachable claims. Test POSTs without credentials and demo submissions with changed fields; require guard parity and no save/password-change claim without an actual operation. Do not enable a production account system as a cosmetic fix.

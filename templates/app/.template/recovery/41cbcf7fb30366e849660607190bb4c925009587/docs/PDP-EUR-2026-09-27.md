# EUR, compact cards and PDP cleanup

Buy now uses a generated pearl-white sedan matching the Sell sedan's canvas and opaque bounds. The existing shortcut sizing and anchors remain. `public/cutouts/BUY-SEDAN-PROMPT.md` records the asset prompt.

`lib/currency.ts` owns the EUR display code and number locale. Prices, monthly amounts, finance inputs, fees, comparisons, service amounts and budget filter labels use this setting. The imported fixture numbers are unchanged, not exchange-rate conversions. Captured highlight descriptions are adapted at the server read boundary; source JSON remains intact. Text EUR labels replace the font-based Dirham glyph.

Mini vehicle cards no longer reserve empty badge space. They show price and monthly estimate on separate compact lines; premium badges sit over the photo. Small inventory-card titles truncate at 390px and below; full names remain in accessible card/link names. Price rows can wrap rather than hiding amounts.

PDP viewing information now links to the showroom, with an outlined location pin and directional chevron. Blue CSS accents, pills, icons, links and their tinted surfaces have neutral equivalents. Existing shapes, dimensions and state behavior remain.

Release assessment: the candidate already lives in Cars `templates/app`. `template-release status` and `discover` list only Auto Best, Modern, Carwow and Import as selected releases. Before client release, App still needs a complete dealer-content boundary, inherited brand/claims/assets cleanup, mounted routing, EN/BG acceptance and exact-source hosted/release evidence. No release lock, client or deployment was changed in this task.

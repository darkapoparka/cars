# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Licensed static reference port served by a small Node runtime.

## Users

Agency OS operators who need an automotive marketplace template variant with the reference site's complete public, dealer, content, and account route surface.

## Product Purpose

Provide a faithful local template variant for approved Agency OS automotive work, preserving the reference page composition, route names, media, and client-side behavior.

## Positioning

This variant is a high-fidelity reference implementation for a specific licensed source, kept separate from the Agency OS-owned showroom, luxury, import, and inventory archetypes.

## Operating Context

The template is mirrored into its own folder, verified locally, and then used only within the scope of the source license and the Agency OS project record. The mirror is static and does not claim a live inventory feed or production account backend.

## Capabilities and Constraints

- Mirrors the reference's homepage variants, inventory/list/map pages, vehicle details, dealer/agent pages, blog pages, FAQ, contact, dashboard, add-listing, compare, and favourites routes.
- Keeps same-origin runtime assets local so local preview does not depend on the public host.
- Exact reuse is authorized by the requester, who represented that the necessary license is held. License evidence is maintained outside this repository.
- Do not redistribute, deploy, or hand off the variant beyond the licensed scope.

## Brand Commitments

The reference identity remains intact in this licensed variant. Lead customization should happen in a separate generated project, never by mutating this master.

## Evidence on Hand

The source URL was supplied by the requester. The mirror script records the acquisition URL, route list, and download timestamp in `mirror/manifest.json`.

## Product Principles

1. Preserve licensed reference fidelity.
2. Keep the variant isolated from other reusable Agency OS archetypes.
3. Keep runtime assets local and auditable.
4. Verify every shipped route before handoff.
